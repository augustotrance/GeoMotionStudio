# Fundación web mínima de G7

Esta aplicación solo demuestra montaje, composición, compilación y smoke técnico de la fundación aprobada. Presenta la identidad de GeoMotion Studio y el estado “Fundación técnica G7”.

No contiene router, estado global, mapa interactivo, creación de Project, persistencia, reapertura, recuperación ni otro comportamiento del recorrido de producto. El spike anterior permanece recuperable en la historia Git del corte G6 y no se duplica en el árbol corriente.
