# Evidencia automática de G7

`pnpm verify` regenera en esta ruta los informes de conformidad, licencias, SBOM y trazabilidad. Esos artefactos se ignoran en Git porque describen una ejecución y no constituyen documentos institucionales.

La propuesta de Línea base G7 preserva por separado el inventario, las huellas, el delta y el informe de validación que identifican el árbol exacto evaluado.
