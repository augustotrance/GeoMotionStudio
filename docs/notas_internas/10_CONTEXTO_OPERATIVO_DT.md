# 1. Propósito

Este documento define la organización del trabajo del Director Técnico
dentro del ecosistema del proyecto.

Su finalidad es establecer cómo la Dirección Técnica coordina misiones,
especialistas, Context Packages y procesos de integración.

No define la autoridad del rol ni los procedimientos detallados de
ejecución.

# 3. Modelo operativo

La Dirección Técnica coordina:

-   misiones;
-   especialistas;
-   Context Packages;
-   procesos de integración.

El modelo operativo busca preservar:

-   contexto suficiente;
-   responsabilidad clara;
-   trazabilidad;
-   continuidad del conocimiento.

---

# 4. Organización mediante misiones

Las misiones representan unidades de trabajo dentro del proyecto.

Cada misión debe disponer de:

-   objetivo;
-   alcance;
-   contexto;
-   responsable;
-   resultado esperado.

Las misiones permiten evolucionar el proyecto de forma controlada sin
perder la visión global.

---

# 5. Relación con especialistas

Los especialistas producen entregables dentro de un alcance definido.

La Dirección Técnica integra los resultados.

Los especialistas:

-   aportan conocimiento técnico;
-   desarrollan propuestas;
-   generan entregables.

La Dirección Técnica:

-   proporciona contexto;
-   mantiene alineación;
-   coordina integración.

---

# 6. Context Packages

Los Context Packages proporcionan el contexto necesario para ejecutar
una misión sin sustituir el Manual de Ingeniería.

Pueden incluir:

-   objetivo;
-   alcance;
-   restricciones;
-   documentación relacionada;
-   antecedentes necesarios.

Los Context Packages:

-   no sustituyen documentos normativos;
-   no crean arquitecturas paralelas;
-   no modifican decisiones aprobadas.

# 8. Integración de conocimiento

Los entregables producidos por especialistas requieren integración antes
de incorporarse al conocimiento institucional.

La integración considera:

-   coherencia;
-   relación con documentación existente;
-   continuidad del proyecto.

---

# 9. Responsabilidad operativa de custodia documental

La Dirección Técnica mantiene la continuidad documental durante la evolución operativa del proyecto.

Dentro del modelo de trabajo, la custodia documental implica:

- identificar qué documentos pueden verse afectados por una misión;
- preservar la relación entre entregables y documentación existente;
- mantener visible el origen de los cambios;
- evitar pérdida de contexto durante la integración de resultados.

Cuando un especialista produce conocimiento que pueda afectar documentación existente, la Dirección Técnica debe asegurar que dicho conocimiento sea integrado dentro del documento correspondiente.

La custodia documental requiere mantener separación entre:

- documentación normativa;
- documentación operativa;
- registros institucionales;
- propuestas no aprobadas.

La integración de conocimiento debe conservar la trazabilidad entre:

Misión

↓

Entregable

↓

Revisión

↓

Documento afectado

↓

Estado resultante


El objetivo operativo es que la evolución del proyecto pueda comprenderse posteriormente sin depender exclusivamente de las personas que participaron en cada etapa.

---

# 10. Gestión de dependencias

Las misiones pueden depender de:

-   decisiones previas;
-   documentos existentes;
-   entregables anteriores;
-   información pendiente.

Las dependencias deben permanecer identificadas para evitar
contradicciones o trabajo duplicado.

---

# 11. Registro operativo

La Dirección Técnica mantiene visibilidad sobre:

-   misiones activas;
-   especialistas involucrados;
-   dependencias;
-   documentos relacionados;
-   resultados pendientes.

---

# 12. Límites del documento

Este documento no define:

-   autoridad del Director Técnico;
-   decisiones arquitectónicas;
-   procedimientos de ejecución;
-   criterios de aprobación.

Su responsabilidad exclusiva es definir el modelo operativo de
organización del trabajo.

---

# 13. Criterio de éxito

El contexto operativo funciona correctamente cuando:

-   cada misión posee contexto suficiente;
-   cada participante conoce su responsabilidad;
-   los resultados pueden integrarse correctamente;
-   el proyecto evoluciona manteniendo coherencia.
