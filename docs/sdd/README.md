Este directorio reúne los instrumentos aprobados para incorporar el Desarrollo Guiado por Especificaciones (SDD) al gobierno de GeoMotion Studio.

**Estado del conjunto:** Aprobado — vigencia diferida hasta la publicación de `LB-G3-GMS-20260904-01`  
**Autoridad:** Founder  
**Trazabilidad:** `ACTO-G3-GMS-20260904-07`; D-19 a D-28  
**Línea base prevista:** `LB-G3-GMS-20260904-01`

## Condición de activación

La incorporación documental de estos instrumentos no activa por sí sola la familia SPEC. El conjunto adquirirá vigencia operativa únicamente cuando la futura Línea base G3 sea aprobada y materialmente publicada.

Hasta entonces:

- no existe una SPEC concreta aprobada por esta actuación;
- no se abre G4;
- `apps/web` permanece sin cambios;
- el código funcional continúa prohibido hasta G9;
- los documentos institucionales aprobados continúan siendo las fuentes de autoridad; y
- los Context Packages conservan naturaleza derivada y no autoritativa.
