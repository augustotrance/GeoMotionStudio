## Reglas

- Una SPEC especializa fuentes institucionales aprobadas; no las sustituye.
- Una SPEC no introduce arquitectura nueva ni completa decisiones ausentes.
- Madurez documental, estado de implementación y publicación se registran por separado.
- La aprobación y la publicación requieren decisiones expresas y separadas.
- Ninguna SPEC autoriza código antes de la Puerta G9 aplicable.
- Los Context Packages son instrumentos derivados de G9 y no fuentes de autoridad.
