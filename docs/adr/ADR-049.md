# ADR-049 · Reemplazo del spike y fundación web mínima

**Código:** `ADR-049`  
**Versión:** `1.0.0`  
**Estado:** Aprobada para incorporación — vigencia diferida hasta la publicación material de `LB-G7-GMS-20260908-01`  
**Fecha:** 8 de septiembre de 2026  
**Autoridad:** Founder  
**Trazabilidad:** `ACTO-G7-GMS-20260908-15`; D-63 y D-66  
**Categoría:** Estratégica  
**Nivel de impacto:** Plataforma  
**Ámbito de aplicación:** `apps/web` y toolchain web  
**Línea base prevista:** `LB-G7-GMS-20260908-01`

---

## 1. Contexto

El Founder declaró `apps/web` un spike reemplazable. Su contenido presenta archivos vacíos, estructura inconsistente, recursos de plantilla y un manifiesto aislado. Ninguno de esos elementos está aprobado como aplicación oficial.

DOC-004 sí establece TypeScript, React y Vite como base institucional. G7 exige una aplicación mínima compilable, sin permitir funcionalidad de producto.

## 2. Alternativas

### A. Promover el spike

Se descarta porque convertiría presencia histórica en adopción, conservaría defectos y eludiría la evaluación de dependencias.

### B. Archivar el spike dentro del repositorio

Se descarta porque duplicaría deuda y podría confundirse con código vigente. Git ya conserva su historia exacta.

### C. Reemplazarlo en la misma ruta

Se adopta: mantiene la ruta oficial de DOC-002, elimina ambigüedad y permite construir desde requisitos vigentes.

### D. Crear otra aplicación paralela

Se descarta porque produciría dos candidatas a aplicación web y requeriría una migración innecesaria.

## 3. Decisión

1. La futura materialización G7 reemplazará íntegramente el contenido corriente de `apps/web`.
2. No se crea copia `legacy`, `archive`, `old` o equivalente.
3. El commit G6 conserva la versión histórica recuperable.
4. `apps/web` continúa como ruta de la aplicación web oficial.
5. Se adoptan exactamente:
   - TypeScript `7.0.2`;
   - React `19.2.7`;
   - React DOM `19.2.7`;
   - Vite `8.1.2`; y
   - `@vitejs/plugin-react` `6.1.1`.
6. La aplicación G7 solo monta una superficie semántica “Fundación técnica G7”, compila y permite smoke.
7. No se incorporan router, gestor de estado global, framework full-stack ni código del recorrido.
8. El punto de composición puede referenciar paquetes vacíos de comportamiento, exports y contratos de prueba, pero no casos de uso funcionales.

## 4. Consecuencias

### Beneficios

- elimina la ambigüedad entre prototipo y producto;
- preserva la ruta institucional;
- usa versiones actuales y exactas;
- reduce dependencias especulativas; y
- deja una base comprobable para G8 y G9.

### Costes

- desaparece del árbol corriente la UI experimental;
- cualquier idea útil del spike deberá justificarse nuevamente desde fuentes vigentes; y
- la aplicación mínima es deliberadamente incapaz de demostrar el recorrido.

## 5. Criterio de no funcionalidad

El cambio G7 deja de ser infraestructura si permite crear, navegar, guardar, cerrar, seleccionar, reabrir o recuperar un Project; presenta Map View interactiva; o materializa decisiones funcionales reservadas a una SPEC. Cualquiera de esas señales bloquea la Línea base G7.

## 6. Verificación

- ningún blob del spike persiste salvo contenido revalidado por necesidad técnica;
- no existe duplicado histórico;
- build y smoke pasan;
- la superficie solo contiene identidad técnica;
- cero imports de módulos funcionales implementados; y
- cero router o gestor global.
